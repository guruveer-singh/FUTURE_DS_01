💡 HOW TO CREATE THESE IN POWER BI/EXCEL:

1. DAILY REVENUE TREND:
   - Import daily_sales.csv
   - Create Line Chart: Date (Axis) → Revenue (Value)
   - Format as smooth line, add data labels for peaks

2. TOP PRODUCTS BAR CHART:
   - Import product_revenue.csv (Top 10)
   - Create Bar Chart: Product (Axis) → Revenue (Value)
   - Sort descending, horizontal orientation works best

3. COUNTRY REVENUE MAP:
   - Import country_revenue.csv
   - Use Map visual (if available) or Bar Chart
   - For Map: Set Country geographic role, Revenue as color intensity
   - For Bar: Top 10 countries by revenue

4. PRICE vs QUANTITY SCATTER:
   - Need to calculate from original data:
     Add column: Revenue = Quantity * UnitPrice
   - Scatter Plot: UnitPrice (X) → Quantity (Y)
   - Size: Revenue, Color: Product Category (if available)

5. PARETO CHART:
   - Import product_revenue.csv
   - Calculate cumulative % revenue
   - Combo Chart: Columns = Revenue, Line = Cumulative %
   - Secondary axis for line chart (0-100%)

6. ORDER VALUE HISTOGRAM:
   - From original data, calculate InvoiceNo-level totals
   - Histogram of: Invoice Total = SUM(Quantity*UnitPrice) by InvoiceNo
   - Bin size: $5-10 intervals work well
